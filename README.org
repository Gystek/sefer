* Sefer

Sefer is a flexible, statically typed, purely functional
data-processing language. At Sefer's core lie /iterators/, which
enable powerful and fast data manipulation.

Sefer is also highly flexible in how it approaches input parsing: any
function can be defined to act as first- or second-level parser, while
preserving code legibility and concision.
